## Notes

MuTube is a YouTube browser and offline player created by Ronax. It needs an
internet connection on first launch to install yt-dlp and FFmpeg. These tools
are not included in the PortMaster ZIP.

The **Media layout** setting supports Automatic detection plus muOS,
EmulationStation (Batocera/Knulli/ROCKNIX), Onion/Garlic/MinUI, and ArkOS.
When moving or copying a download, its JPG thumbnail is placed in the matching
box-art folder using the same video filename stem.

Thanks to the yt-dlp, FFmpeg, SDL2, and PortMaster projects.

## Controls

| Button | Action |
|--|--|
| A | Play/select |
| Hold A | Action menu |
| B | Back/cancel loading |
| X | Text search |
| START | Download selected video |
| D-pad / L1 / R1 | Navigate and seek during MPV playback |
